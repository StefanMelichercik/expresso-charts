L’application garde vos données sur votre ordinateur

  • Vos charts, dispositions, réglages et sauvegardes sont stockés uniquement sur votre ordinateur, chiffrés avec la protection propre à Windows. Ils ne sont jamais envoyés, ni à nous ni à personne.
  • Les captures d’écran que vous importez sont traitées localement et ne sont envoyées nulle part.
  • Pour placer les charts, l’application lit la position et le titre des fenêtres de poker à l’écran. Ces informations restent sur votre ordinateur.
  • Les licences sont liées à un code machine : une empreinte à sens unique de votre installation Windows. Il ne contient aucune information personnelle.
  • Le fichier de diagnostic n’est créé que si vous cliquez sur « Enregistrer le diagnostic », et il n’est envoyé que si vous nous l’envoyez vous-même. Il ne contient aucun chart.
  • L’application consulte un fichier public sur GitHub pour savoir si une version plus récente existe et, lorsque vous choisissez de mettre à jour, télécharge la nouvelle version depuis GitHub. Ces requêtes ne contiennent aucune information vous concernant ; GitHub peut enregistrer votre adresse IP comme lors de toute visite d’un site web (voir la déclaration de confidentialité de GitHub).

Lors d’un achat

Les achats sont gérés par Gumroad en tant que Merchant of Record. Gumroad traite vos nom, e-mail, adresse de facturation et données de paiement selon sa propre politique de confidentialité. Nous recevons vos nom, e-mail, pays, détails de commande et le code machine saisi lors du paiement, afin de livrer et d’assister votre licence.

Lorsque vous nous écrivez

Nous utilisons votre e-mail et votre message uniquement pour vous répondre et garder une trace de l’assistance et des licences émises.

Ce site web

Ce site n’utilise ni outil d’analyse, ni publicité, ni cookies de suivi. Il est hébergé sur GitHub Pages, qui peut enregistrer l’adresse IP des visiteurs pour des raisons de sécurité.

Durée de conservation

Les données de commande et de licence sont conservées aussi longtemps que l’exigent les règles fiscales et comptables, puis supprimées. Les e-mails d’assistance sont conservés jusqu’à 2 ans.

Vos droits

Vous pouvez nous demander une copie de vos données, leur rectification ou leur suppression (sauf obligation légale de conservation), et vous pouvez déposer une réclamation auprès de votre autorité de protection des données (en France, la CNIL). Contactez-nous à l’adresse ci-dessus.
